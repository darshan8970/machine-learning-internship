## What I covered

### 1. Logistic Regression

I worked through the main ideas behind logistic regression, including:
- **Motivation and examples:** when classification is useful and why a regression-style name can be confusing at first.
- **Hypothesis and model representation:** how logistic regression produces a prediction for a class using input features.
- **Decision boundaries:** how a model separates different classes based on its learned parameters.
- **Cost function:** how we measure prediction error during training.
- **Multiclass classification:** how classification can be extended beyond two classes.

### 2. Evaluating and improving a model

In Module 4, I studied concepts that help explain how well a model performs and what can go wrong:
- **Underfitting and overfitting:** recognizing when a model is too simple to capture patterns or fits the training data too closely.
- **Model evaluation:** checking how well a model performs, rather than judging it only by its training results.
- **Regularization:** a technique used to help control model complexity and reduce overfitting.
- **Bias and variance:** understanding two sources of error and the balance involved when building a model.
- **Error analysis:** looking more closely at mistakes to understand where a model struggles and what might be improved.
