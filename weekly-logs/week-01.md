# Week 1 — Machine Learning Internship

This week was mainly about getting familiar with the basics of Machine Learning and building a foundation for the topics that come next.

## What I covered

### 1. Introduction to Machine Learning
I started with the basic idea of Machine Learning: how a system can learn patterns from data and use them to make predictions or decisions, instead of being programmed with a separate rule for every situation.

### 2. Supervised Learning
I learned what supervised learning means and how it uses labelled examples. The model learns from input data paired with known answers, then uses what it has learned to make predictions on new data.

### 3. Unsupervised Learning
I also went through unsupervised learning, where the data does not come with labelled answers. The goal is to find patterns, groups, or structure in the data.

### 4. Vectors and Matrices
I covered the basics of vectors and matrices and why they matter in Machine Learning. They provide a way to represent and work with data mathematically, and they are especially useful when dealing with multiple features and model calculations.

### 5. Linear Regression
I moved on to linear regression and worked through its main ideas:
- **Intuition:** understanding how a model fits a line to represent the relationship between input features and a target.
- **Cost function:** measuring how far the model's predictions are from the actual values.
- **Cost function intuition:** understanding what the cost tells us about a model's performance and why we want to reduce it.
- **Gradient descent:** learning how a model can adjust its parameters step by step to reduce the cost.
- **Learning rate:** understanding how the size of each update affects the learning process.
- **Multivariate linear regression:** looking at linear regression with more than one input feature.

## Practice

I also had worksheets for Module 1 and Module 2. They gave me a chance to review the concepts instead of only watching or reading the lessons.

## My takeaway

This week helped me connect the high-level idea of Machine Learning with some of the maths behind it. Linear regression made the learning process feel more concrete: a model makes predictions, a cost function measures the error, and gradient descent updates the parameters to try to improve those predictions.

I still have more practice ahead, but these are the foundations I'm building on as I continue through the internship.
