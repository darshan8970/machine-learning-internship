# Machine Learning Internship — 12-Week Journey

This repository is where I'm documenting my 3-month Machine Learning internship, one week at a time.

Instead of keeping everything I've learned in one place, I want to maintain a record of my progress throughout the internship — including the concepts I learn, the work I do, the problems I run into, and the things I figure out along the way.

The goal is to keep track of my journey from the beginning to the end of these 12 weeks.

## What You'll Find Here

- **Weekly learning logs:** Concepts and topics covered during each week.
- **Practical work:** Exercises, implementations, and experiments.
- **Problem-solving:** Errors, bugs, challenges, and how I approached them.
- **Progress updates:** Key takeaways and how my understanding develops over time.
